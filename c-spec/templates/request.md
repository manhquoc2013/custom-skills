# REQUEST.md template

`<...>` fill in · `<a | b>` pick one · `<none, or ...>` default `none` · anything else is literal.

The raw ask, captured before research. Read it to see what the user originally wanted and where that came from.

```markdown
# REQUEST

## Goal
<one sentence: what the user asked for, in their words>

## Audience
<who it is for>

## Progress
### Now
<intake: the ask is captured, research has not started>
### Done
<what has been gathered so far, one line each, or none>
### Open
<what the ask still leaves unsaid, one line each, or none>
### Next
<the single next action>

## Constraints
<limits the user stated, one per line, or none>

## Source
<the doc path or link this came from, one per line, or this prompt>
```
