# maps/{slug}.md template

`<...>` fill in · `<a | b>` pick one · `<none, or ...>` default `none` · anything else is literal.

The fog map for one destination. One file per charted destination. Read it to see how far the charting has got and what is still unexamined.

```markdown
## Destination
<one or two lines: the spec, decision, or change being charted>

## Progress
### Now
<the area being charted right now>
### Done
<areas already charted, one line each, or none>
### Open
<fog still unmapped, one line each, or none>
### Next
<the next area to chart>

## Decisions so far
<one decision per line, or none>

## Not yet specified
<one open question per line, or none>

## Out of scope
<what this destination will not cover, one item per line, or none>
```
