# RETRO.md template

`<...>` fill in · `<a | b>` pick one · `<none, or ...>` default `none` · anything else is literal.

The accepted candidates from one retro. A candidate the user rejected is not recorded.

```markdown
# RETRO

## Session
<the session or slug this retro covers>

## Progress
### Now
<the retro itself, after the run it reviews>
### Done
<candidates already applied, one line each, or none>
### Open
<candidates still awaiting a decision, one line each, or none>
### Next
<the next candidate to act on, or none>

## Candidates
### <one line: the change>
Category: <navigation | checks | standards | steering | tools | information>
Evidence: <what happened in the session>
Prevents: <the failure it would stop>
Verdict: <accepted | rejected | undecided>
```
