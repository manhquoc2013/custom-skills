# AI context

## 1. Current architectural state

Skill pack tại root repo. Phiên bản `VERSION`: 1.5.0. Cài bằng bản copy, không symlink.

Luật cốt lõi nằm ở mục Floor trong `c-agents`. Pack chạy khi Superpowers, mattpocock, hoặc ui-ux-pro-max chưa cài. Skill cài thêm được đọc kèm, không thay Floor. `c-flow` làm một feature. `c-loop` là vòng theo lịch hoặc sự kiện.

Hình dạng các file skill ghi ra nằm trong thư mục `templates/` cùng thư mục với `SKILL.md`, mỗi tài liệu một file, không nhúng trong `SKILL.md`. Skill chỉ đọc đúng file template của tài liệu sắp ghi. Quy ước placeholder (`<...>` điền, `<a | b>` chọn một, `<none, or ...>` mặc định `none`) ghi ở dòng đầu mỗi file template.

## 2. Recent changes

- Tách toàn bộ khối template còn nhúng trong 8 skill (`c-flow`, `c-spec`, `c-implement`, `c-agents`, `c-loop`, `c-debug`, `c-design`, `c-prompt`) ra thư mục `templates/` riêng, mỗi tài liệu một file, viết lại theo placeholder `<...>` và union `<a | b>`.

Skill khác chỉ gọi `c-debug` cho bug khó. Sai cú pháp, lint, thiếu code không vào skill đó.
