# AI context

## 1. Current architectural state

Skill pack tại root repo. Mỗi skill là một thư mục `SKILL.md`. Không có runtime app.

`processing-the-flow` là luồng làm feature: hỏi slot context, người dùng xác nhận danh sách `REQ-`, rồi plan → execute → verify → ship. Mỗi cổng bắt buộc đọc skill Superpowers tương ứng (brainstorming, writing-plans, using-git-worktrees, test-driven-development, requesting-code-review, subagent-driven-development hoặc executing-plans, systematic-debugging, verification-before-completion, finishing-a-development-branch). File trạng thái vẫn là `work/{slug}/`. `PASS` chỉ khi output lệnh khớp kết quả trích từ dòng `REQ-`.

`running-the-loop` là vòng bảo trì theo lịch, bắt đầu ở L1. README là hướng dẫn cài và gọi skill.

## 2. Recent changes
